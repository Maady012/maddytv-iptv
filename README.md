# Maddy TV IPTV

Automated IPTV playlist generator for high-quality live Tamil TV, Movies, Sports, and Entertainment streams.

## Features
- Direct high-speed CDN token resolution for live streams.
- Curated Tamil entertainment, movies, sports, kids, and infotainment channels.
- Support for Kodi ClearKey DRM streams.

## Output
- `maddytv.m3u`

## Usage
Run the generator script to update stream session tokens:
```bash
python3 scraper.py
```
